# Put the raw Olist CSVs here

Download "Brazilian E-Commerce Public Dataset by Olist" from Kaggle and copy these 9 files into this folder
(keep the original names):

- olist_customers_dataset.csv
- olist_geolocation_dataset.csv  (optional - not used in the analysis)
- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_order_payments_dataset.csv
- olist_order_reviews_dataset.csv
- olist_products_dataset.csv
- olist_sellers_dataset.csv
- product_category_name_translation.csv

These files are git-ignored on purpose (size + dataset license).
